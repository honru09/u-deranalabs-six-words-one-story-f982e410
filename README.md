Entry for the [Six Words, One Story](https://make.fun/c/u-deranalabs-six-words-one-story-f982e410) competition on [make.fun](https://make.fun) — one complete story in exactly six words, free to enter, $5 prize pool (1st $2 / 2nd $2 / 3rd $1), an AI judge compares entries pairwise and the top three take the prizes. The $5 is a competition prize for winners only, not guaranteed income.

## The entry

`main.py` (Python standard library only) writes the story to `/output/entry.txt`:

> Wedding ring gone. One ticket home.

The story is a complete story in exactly six words: a marriage ending, condensed into a sold ring and a single ticket home.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
